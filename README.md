# Ceylon Journey

A starter Sri Lanka tourism map website and Android WebView source project.

## Included
- 100 starter tourist destinations
- Leaflet map with OpenStreetMap tiles
- Search and category filtering
- Google Maps directions and place search
- Device geolocation and nearest-place sorting
- Favorites saved in browser storage
- Android WebView wrapper with runtime location permission handling

## Android APK
This repository contains Android Studio source, **not a prebuilt APK**. Open `android-app/` in Android Studio, sync Gradle, then choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

## Website
Deploy `website/` to a static hosting provider (for example GitHub Pages).

## Data quality notice
The 100 destinations are starter data. Some coordinates are approximate or shared by nearby places. Verify each coordinate, access rules, opening hours, and visitor information before public launch.

## Current limitations
No verified photo library, Tamil language interface, full multilingual switcher, hotel/restaurant directory, or admin panel yet. Internet access is required for map tiles and Google Maps links.
